# flash as the C++ firmware leaves it after installing install-check (app1 selected, new), the C++
# release on the card. install-check hands the next boot back, starts writing the release over
# app0 ("Rewrite"), and the device is reset in the middle. The bootloader then finds no image
# that passes in app0 and falls back to app1: install-check runs again, notes the last line the
# first run left ("earlier: ..."), writes the release over app0 ("Repair") and resets into it.
