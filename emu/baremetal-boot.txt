# Firmware Update flashes it into the other OTA slot and restarts into it. It hands the next boot
# back to this firmware, reads the bootloader (here the C++ build's), clears its own appended
# digest, selects its own slot and resets. The bootloader checks it, refuses it ("OTA app

# reset is refused the same way, but eink-qemu then takes the bootloader's "Image hash failed"
# line for a crash, so the scenario stops here.)

#   emu/compare.sh emu/baremetal-boot.txt x4pro build/baremetal/a-boot-check.bin
