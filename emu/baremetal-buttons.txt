# rust/firmware's button-check image counts presses of Left, Right and Power from the bare-metal
# firmware; a long Power press ends the count, and it resets into this firmware, which saves the
# report.
# Settings > System > SD Card Firmware Update flashes it into the other OTA slot.
#   cd rust/firmware; cargo build --release; cd ../..
#   espflash save-image --chip esp32s3 --flash-size 16mb rust/firmware/target/xtensa-esp32s3-none-elf/release/button-check build/baremetal/button-check.bin
#   emu/compare.sh emu/baremetal-buttons.txt x4pro build/baremetal/button-check.bin
# The emulator waits about 3 s before each press, so the presses here fit the image's 40 s. The base
# side fails at its first wait for the image's output: the unmodified base firmware never starts
# the image.
