# The SD updater's install over a write cut short (rust/firmware's install-check): a cold boot of
# a flash whose app0 (the C++ firmware, selected) no longer passes, install-check in app1, and the
# C++ release on the card. The bootloader finds no image that passes in app0 and falls back to
# app1; install-check writes the release over app0 ("Repair"), reads it back and resets into it.
#   (make build/baremetal/flash/ as emu/make_install_flash.py says)
#   (bash or zsh; in fish write `set Q ...` and `set R ...`)
#   Q=~/Documents/bembeyaz/tools/eink-qemu-0.9.2/qemu/bin/eink-qemu
#   R=build/baremetal/recovery/purestwhite-recovery.bin
#   $Q run build/baremetal/flash/cut-first.bin --machine x4pro --sleep on --put $R --script emu/baremetal-repair.txt
#   $Q run build/baremetal/flash/cut-mid.bin --machine x4pro --sleep on --put $R --script emu/baremetal-repair.txt
#   $Q run build/baremetal/flash/cut-half.bin --machine x4pro --sleep on --put $R --script emu/baremetal-repair.txt
# Without --put the card holds no release: install-check notes "card: File(NotFound)" and sleeps
# ("sleep: deep, no C++ image"), and this scenario fails at its wait for the card line. Run
# instead: $Q run build/baremetal/flash/cut-mid.bin --machine x4pro --sleep on timeout:120
# 'wait-log:sleep: deep' wait:3 press:power 'wait-log:purestWhite install' 'wait-log:earlier: sleep'
# (Power wakes it, the bootloader falls back again, and the earlier run's last line is noted).
# start-cut.bin: the first run notes "refused: Unconfirmed" and sleeps; after Power, the bootloader
# falls back and the next run repairs: $Q run build/baremetal/flash/start-cut.bin --machine x4pro
# --sleep on --put $R timeout:120 'wait-log:refused: Unconfirmed' 'wait-log:sleep: deep' wait:3
# press:power 'wait-log:Repair: [0-9]+ sectors' 'wait-log:installed: same digest' wait-log:done
